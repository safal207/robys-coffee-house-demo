# Complete menu photography v1

This evidence pack covers the visual asset set used by the full menu.

- 61 individual menu product photos, each 1024 × 1024 WebP
- 5 clean pairing photos, each 1024 × 1024 WebP
- Hot cups, cold cups and every pairing vessel visibly carry the `ROBY'S COFFEE HOUSE` brand
- Product names and prices are not baked into the photography; localized HTML remains authoritative
- The original menu inventory and all verified prices remain unchanged

Review sheets:

- `beverages.webp` — hot coffee, brewed drinks, cold coffee, refreshers and herbal tea
- `desserts-food.webp` — desserts, croissants, sandwiches and simit
- `sets.webp` — the five same-style pairing compositions

The executable completeness contract is `scripts/verify-menu-image-assets.mjs`.
