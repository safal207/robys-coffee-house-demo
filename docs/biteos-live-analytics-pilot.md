# BiteOS / Robys local analytics pilot

This draft adds a local-only runner, not production tracking. It compiles the existing menu source in memory and never writes generated production assets. From a trusted checkout: npm ci; node --test scripts/test-biteos-live-pilot.mjs; node scripts/biteos-live-pilot.mjs. Open the printed localhost URL. Opt in to test-event recording; interact with actual feed photos, likes, direct add-to-cart and share; export JSON. Stop erases the in-memory session. Reload loses the session. No upload, localStorage analytics, identity, raw URL, IP or geolocation in export. Existing menu favorites and cart retain their original storage behavior. Share completion means native action resolved or clipboard succeeded, not recipient or purchase. Views come from the original model's qualified per-page view, not clicks. A view already counted before consent is not retroactively imported. Direct feed cart action only; editor, combos, other routes and checkout not instrumented yet. The session starts at opt-in, not actual site arrival. No server event collector or public-cafe data. The snapshot contract is compatible with BiteOS scripts/robys-engagement.mjs at a7bb0a89054e6f99bc95ab105bbf9f09b466540a; use its catalog IDs and aggregate command to import into Growth Dashboard. Owner approval, consent text review, retention, reliable ingestion and integrated browser testing are prerequisites for production. No dependencies added. Existing committed bundles and integrity manifest remain unchanged.
