# Applied SEO / AEO / GEO Case Study — Roby's Coffee House

**Started:** 2026-08-11  
**Live site:** https://safal207.github.io/robys-coffee-house-demo/  
**Market angle:** Russian-language discovery + Yandex-oriented technical/local SEO for a real service website.

> This is a current applied portfolio case. It is not presented as prior 3+ years of commercial SEO experience. Results are recorded only after they are actually measured.

## Goal

Turn an existing production-oriented local business website into a measurable SEO case with a transparent evidence trail:

`baseline → search intent → technical changes → crawl/index controls → structured data → AEO/GEO content → measurement → result`

## Why this project is useful as an SEO case

The site already has a real customer-facing surface rather than a blank demo: multilingual storefront, menu, local business data, GitHub Pages deployment, analytics hooks and a QA pipeline. That makes the SEO work an optimization problem, not a greenfield checklist exercise.

## Initial implementation scope

1. Preserve correct existing canonical / robots / structured-data behavior.
2. Add a crawlable Russian-language landing page for relevant local intent.
3. Improve sitemap freshness and URL coverage.
4. Add machine-verifiable SEO checks to the repository.
5. Record every change and its intended metric before measuring outcomes.

## Success criteria

The case is successful when a reviewer can independently answer:

- What was the baseline?
- What search intent was targeted?
- What exactly changed in code/content?
- Why was that change made?
- How is it verified technically?
- Which metric should move?
- What actually moved after enough data was collected?

No traffic, ranking, CTR or conversion improvement is claimed until it is observed.
